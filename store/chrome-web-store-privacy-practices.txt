═══════════════════════════════════════
1) SINGLE PURPOSE DESCRIPTION (required)
═══════════════════════════════════════

Detects prices on web pages and converts them to the user’s preferred currency using public exchange rates from Frankfurter.


═══════════════════════════════════════
2) PERMISSION JUSTIFICATIONS (required)
═══════════════════════════════════════

Only paste justifications for permissions that appear in the dashboard form for this package.

--- storage ---
Used only to save the user’s preferences on their device (preferred currency, conversion mode, display options) and to cache exchange rates temporarily so the extension does not repeatedly call the rate API. Settings and cache never leave the user’s browser for advertising or sale.

--- Host permission: https://api.frankfurter.dev/* ---
Required to fetch public mid-market exchange rates from the Frankfurter API (https://frankfurter.dev / https://api.frankfurter.dev). The extension only requests rate data needed for currency conversion. No browsing history is uploaded to the developer. No other hosts are contacted for conversion.

--- Content scripts / broad site access (matches: <all_urls>) ---
(Use this if the form asks why the extension can read or change data on all websites.)

Required because NK Currency converts prices on arbitrary websites the user visits. Content scripts are declared in the manifest (not injected with the scripting API). They read visible page text only to find currency amounts and show converted values when conversion is enabled. Default mode is click-triggered from the popup; full realtime conversion is optional in Settings. No ads, trackers, or unrelated code are injected.


═══════════════════════════════════════
3) REMOTE CODE USE (required)
═══════════════════════════════════════

Select: No, I am not using remote code.

Justification / explanation (if a text box is shown):
This extension does not download or execute remote JavaScript. All extension logic ships inside the package (popup, options, background service worker, and content scripts). The only network calls are HTTPS requests to https://api.frankfurter.dev for JSON exchange-rate data, which is used as data—not executed as code.


═══════════════════════════════════════
4) DATA USAGE / CERTIFICATION (required)
═══════════════════════════════════════

In the data collection checkboxes:
• Select that you do NOT sell user data / use it for ads.
• Personally identifiable information: none collected by NK Currency.
• Honest summary: preferences and rate cache are stored locally with chrome.storage; no personal data is sent to the developer. Rate API calls go from the user’s browser to Frankfurter only.
